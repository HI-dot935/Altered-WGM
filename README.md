# 🕵️ Altered-WGM – Ultimate OSINT Workbench

**Altered-WGM** combines:
- **RAWS**-style case management & dashboard
- **Epieos** email/phone intelligence
- **Holehe** deep account scan (120+ sites, with clickable links)
- **XposedOrNot** free breach detection (no API key)
- **150+ username sites** (Pinterest, Reddit, TikTok, GitHub, etc.)

## Features
- 📧 Email: validation, MX, optional HIBP breaches
- 📱 Phone: validity, type, location, carrier
- 🔍 Deep Account Scan (Holehe) – 120+ sites
- 🔐 Breach Check (Xposed) – keyless
- 👤 Username Search – 150+ sites (async)
- 🌐 Domain Recon – MX records
- 📂 Case logging & Markdown export
- 🖥️ Web UI with sidebar
- ⌨️ CLI: `altered-wgm -e target@example.com`
- 🐳 Docker support
- 📦 pip‑installable
